# Verified scene rendering

T11 implements `Renderer` and `FFmpegRenderer`, using the same graph builder for frame and clip requests. `FrozenRegistry` checks every snapshot lock against the current registry, then verifies actual master hashes. It repeats these checks after rendering. Draft edits or in-place file changes invalidate the operation. Production rendering requires the frozen snapshot's explicit hash-bound approval as well as approved input records.

The graph follows template slot order. Static layers match the design canvas after any explicit crop. Character actions use the compiled source frame and the difference between the template's seat anchor and the pack's anchor. Body and face channels stay independent. Masks multiply existing alpha rather than replacing it, so transparent exterior regions retain transparency. Foreground layers composite afterward wherever the template orders them.

Each invocation normalizes only needed PNGs into an owned temporary folder, verifies their decoded bytes, and creates hard links to those copies for the requested prepared frame ranges. Source artwork is never linked into a deletion target or edited. Stills and sequences use straight alpha; explicitly declared premultiplied inputs are unpremultiplied first. Tagged color is converted to sRGB; untagged draft images are interpreted as sRGB with a warning. Unknown production color is rejected. Raw grayscale masks never undergo an ICC/gamma conversion.

Still previews are RGB PNGs. Video output is H.264, YUV420P, limited-range BT.709 MP4 with a front-loaded media index. Software encoding and VideoToolbox have explicit settings; hardware fallback is disabled. The graph uses argument-array input filenames and numeric filter expressions, written as UTF-8 to a graph file. This uses FFmpeg's documented [filtergraph/overlay interfaces](https://ffmpeg.org/ffmpeg-filters.html#overlay) and [image-sequence demuxer](https://ffmpeg.org/ffmpeg-formats.html#image2-1).

After encoding, verification checks the actual stream codec, canvas, pixel/color format, frame count and every rational presentation timestamp, then strictly decodes the whole output. A final name is created atomically without clobbering only after these checks. Still outputs are fully decoded and checked too. Reports include source snapshot, graph/backend/toolchain identities, output hash, timing and warnings. Render subprocess timing excludes normalization and verification.

Current bounds are 7,200 frames and 128 inputs per graph. Static/character slots, grayscale masks, opacity, cut concatenation, letterbox and crop are implemented. Unsupported slots fail rather than disappearing. T12 adds moving strips and scheduled landmarks; later tasks add effects, audio and overlap semantics. Prepared PNG sequences are the alpha-media interchange fallback; importable video is not automatically a renderable character pack. No long-form memory/performance claim follows from the small fixture test.

Reproduce technical checks with `make test-media`. [T11 evidence](tasks/t11.md) includes a full ten-second local clip and an inspected PNG. Its exterior is explicitly stationary/cropped for this task; it is not a completed visual pilot or approved Tabi artwork. CLI frame/preview adapters enter in T13.
