# Local artwork and media

Selected static TABI/train references remain tracked here. They are source references, not
publication-approved assets. Import the chosen reference through the guided workflow and
review its exact hash and rights.

Bulk breath/drink sequences, walking poses, outfit/emotion variants and Tokyo panoramas remain
at their original local paths. F13 removed them from the Git index to reduce the tracked tree;
it did not delete or modify them. The [local inventory](../evidence/f13-local-media-inventory.json)
records every preserved path, byte count and SHA-256.

Fresh clones do not contain those ignored variants or any MP4. Keep them in backed-up media
storage and copy/import the needed source through the app. Existing local projects and immutable
asset versions remain unchanged. Do not add the bulk source directories back to Git; an approved
edit creates a new asset version in project storage.

F13 does not rewrite existing Git history or reduce the disk used by preserved local media.
The [source audit](../09-implementation-review.md) and original [inventory](../asset-inventory.json)
retain earlier provenance/preparation findings. Artwork timing, likeness and commercial rights
still require review.
